# Урок 13. MCP: підключення готових серверів (клієнт)

> 🚧 **Урок готується.** Нижче — що в ньому буде.
> Слідкуйте за оновленнями репозиторію.

!!! abstract "Мета уроку"
    Дати агентові інструменти з будь-якого MCP-сервера.

- Що таке MCP і навіщо він потрібен: один протокол замість окремої
  інтеграції з кожним сервісом
- Архітектура: агент — клієнт, сервер надає інструменти (`tools/list`, `tools/call`)
- Транспорти: `stdio` (локальний процес) і HTTP (віддалений сервер)
- Обгортка `MCPTool(Tool)`: інструменти сервера реєструються поруч з власними
- Опис серверів у `config.toml` (`[mcp.servers.<ім'я>]`)
- Асинхронний SDK і синхронний агент: як їх поєднати
- Безпека: описи й результати чужого сервера — недовірений текст

**Знадобиться далі:** Git-асистенту — офіційні MCP-сервери GitHub і GitLab
замість написання власних інструментів для PR/MR та issues.

!!! example "Практика"
    Підключіть MCP-сервер файлової системи й порівняйте
    його інструменти з власними `list_files` / `read_file`.
