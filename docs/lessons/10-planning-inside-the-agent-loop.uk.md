# Урок 10. Планування в агентному циклі

> 🚧 **Урок готується.** Нижче — що в ньому буде.
> Слідкуйте за оновленнями репозиторію.

!!! abstract "Мета уроку"
    Навчити агента не вгадувати, а уточнювати й планувати.

- `ask_user` — агент сам ставить уточнювальне питання посеред роботи
- `todo_add` / `todo_update` / `todo_list` — агент веде список задач
  і відмічає виконані, як це роблять агенти для коду
- Коли питати користувача, а коли вирішувати самому

**Знадобиться далі:** SDD — фаза уточнення вимог і список задач;
Git-асистенту — уточнення перед ризиковими діями.

!!! example "Практика"
    Дайте агентові розмите завдання («зроби інструмент для курсу валют»)
    і подивіться, які питання він поставить і як розіб'є роботу на кроки.
