# Урок 3. Інструменти (tool calling)

> 🚧 **Урок готується.** Нижче — що в ньому буде.
> Слідкуйте за оновленнями репозиторію.

!!! abstract "Мета уроку"
    Зрозуміти, як модель «використовує» інструменти, не виконуючи код.

- Модель лише *просить* виклик функції, виконує його наш код
- Опис інструменту в JSON Schema
- Клас `Tool` і реєстр `ToolRegistry`
- Розбір інструменту `calculator`
- Чому опис кожного інструменту коштує токенів у *кожному* запиті
- Команда `/debug`: сирі запити й відповіді моделі

!!! example "Практика"
    Через `/debug` знайдіть момент, коли модель просить калькулятор,
    і момент, коли отримує результат.
