# Урок 8. Виконання команд і тестів

> 🚧 **Урок готується.** Нижче — що в ньому буде.
> Слідкуйте за оновленнями репозиторію.

**Мета:** дати агентові запускати команди, не втрачаючи контролю.

- `run_command`: дозволений список команд, підтвердження, тайм-аут
- Обрізання довгого виводу: перші й останні рядки замість тисяч рядків
- `run_tests`: запуск `pytest` і короткий підсумок (скільки пройшло, що впало і чому)
- Маскування секретів: токени й паролі не повинні потрапити ні моделі,
  ні в архів сесій

**Знадобиться далі:** Git-асистенту — для git-команд і аналізу логів CI;
SDD — для перевірки кожної задачі тестами.

**Практика:** попросіть агента запустити тести проєкту, знайти причину падіння
(навмисно зламайте один тест) і запропонувати виправлення.
