# Урок 5. Свій перший інструмент

> 🚧 **Урок готується.** Нижче — що в ньому буде.
> Слідкуйте за оновленнями репозиторію.

!!! abstract "Мета уроку"
    Написати власний інструмент і підключити його до агента.

- Інструмент `current_time` крок за кроком
- Чому опис (`description`) важливіший за код
- Результат інструменту читає модель, а не людина: короткий простий текст, без кольорів
- Тестування інструменту через `pytest`

!!! example "Практика"
    Напишіть самостійно `exchange_rate` (відкрите API НБУ)
    або `get_weather` (Open-Meteo).
